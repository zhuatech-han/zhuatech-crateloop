# CrateLoop 架构与领域规则

知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 微信 zhuatech / zhuatech2。

浏览器→同源Nginx→SpringBoot→MySQL。公开学习版采用单组织、部门范围和伙伴绑定。SpringSecurity会话、CSRF、BCrypt密码、数据库实时权限；全局写事务锁保护数量、子账、状态和命令重试一致性。Flyway建表，Hibernate仅校验。

Pool：总量、可用、发出预留、发出在途、伙伴保管、归还预留、归还在途、待检、维修、遗失、报废。池总量等于十桶之和。伙伴保管和归还预留分别等于伙伴子账之和；发出预留/在途、归还在途和待检还须与未完成业务单匹配。

Movement：ISSUE/RETURN单，每单一个池、一个伙伴、整数数量，独立审批/双边签收/短缺复核/独立质检，取消只允许未发运状态。Adjustment：ADD/REPAIR/RETIRE提案，独立审核后改变池；维修提案未审核不预留资源，审批时重新检查余额。LedgerEntry：追加状态桶迁移，含伙伴、来源类型/单号、操作人和微秒UTC时间，无更新删除接口。BalanceStatement：伙伴当前量及截止流水快照，确认时检测后续变动。

所有业务写入使用UUID和记录版本。重复UUID必须同账号、动作、对象与完整载荷，不再次过账；旧版本、余额不足、双人规则或数量守恒失败整个事务回滚。公开学习版有界目录、全局串行写锁；不宣称大规模性能验收。
